Lectern 1.1.0

Ollama support, sidebar ⋯ menus, notes from a link, and a formatting toolbar with comments

Added

  • Ollama as an AI provider (Settings → AI), like Atlas's Local mode: use free models running on your Mac (localhost:11434), or Ollama's hosted models at ollama.com with an Ollama API key kept in the Keychain. Every AI feature works with it; models that can see images also explain diagram slides. Onboarding offers “Use Ollama instead”.
  • A ⋯ button on subjects and folders in the sidebar (and on pages when you point at them) with New Page, New Folder, Rename, Duplicate, Move, Show in Finder, Export and Move to Trash, so you don't need to right-click.
  • “Notes from a link” on every page: paste a link to an article, PDF, PowerPoint, Word file or Google Doc (or open one in Lectern's browser if it needs your iLearn login), and the AI adds a summary, key points, notes, key terms and questions to the bottom of the page. The link is saved in the page's sources.
  • A formatting toolbar above every page: text style (Text, Title, Heading 1–3, Quote, Code), font size, bold, italic, underline, strikethrough, text colour, highlight colour, links, comments, lists and undo/redo. Underline and Comment are also in the selection toolbar.
  • Comments: select text and add a note to it; click the text to read, edit or resolve the comment. Comments, colours and sizes are saved in the Markdown, so they survive opening the page elsewhere.
  • Settings → Appearance can hide the formatting toolbar.

Fixed

  • Lectern now always opens its main window when it starts, even if the window was closed when you last quit.
