Lectern 1.2.0

Flashcards saved in pages, Summarise Subject with PDF export, and clearer Ollama setup

Added

  • **Summarise Subject…** in a subject's ⋯ menu (under Glossary): reads every page in the subject and writes a brief summary of the important content (overview, topic by topic, key terms, how ideas connect, focus for the exam) to a “📋 Subject Summary” page you can edit. Large subjects are summarised in parts, so it works with local Ollama models too.
  • **Export Summary as PDF…** in the subject's ⋯ menu (under Archive Subject): exports the finished summary as a PDF with a cover page.
  • Flashcards you make from a page are also saved in that page, in a “🃏 Flashcards” section: each card is a toggle (click the question to see the answer), with a link to the deck where they're studied. This covers AI-generated cards, “Make flashcard” from highlighted text and New Flashcard from a page.
  • An “Open Ollama” button in Settings → AI and on AI errors when Ollama isn't running on your Mac.

Fixed

  • When the chosen Ollama server (for example ollama.com) doesn't have the selected model, Settings → AI now says so and offers “Use Local (this Mac)”, and the error names the server instead of saying the model is missing.
