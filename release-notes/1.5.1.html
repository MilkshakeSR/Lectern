Lectern 1.5.1

Flashcards work reliably with local models; drop highlight fixed

Fixed

  • Making flashcards no longer fails with "couldn't be read" when a local model writes slightly broken data. Lectern repairs the reply, keeps every card it can read and tries once more if needed. Quizzes benefit too.
  • Cards labelled fill-in-the-blank with no blank are now normal cards, so they come up for review.
  • Error messages no longer say "Claude" when you're using Ollama.
  • Dragging a file over the notes bar highlights only the box it drops into.
