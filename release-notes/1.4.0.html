Lectern 1.4.0

Full-length summaries, subject PDF export, flashcard improvements, better editor, Planner upgrade

Added

  • **Summaries of any length.** Notes, summaries, flashcards and quizzes now read the whole source in sections (map, merge, verify). Every slide must be covered by a specific note; missed slides get catch-up passes, and anything still missing is listed with the reason. Notes end with a coverage report.
  • Ollama: an explicit context size on every request (safe for this Mac's memory, adjustable in Settings → AI), streaming, diagrams read by an installed vision model or noted as unreadable.
  • Resumable AI jobs: finished sections are saved, long jobs run in the background with a sidebar progress ring, an estimated time left, and a notification.
  • Settings → AI: Model advisor, a benchmark that compares installed models, and a model choice for each task.
  • Export a subject or folder as one PDF: choose and reorder pages, cover, contents with page numbers, bookmarks, header and footer, flashcard tables, glossary, assessments, attached PDFs as appendices, live preview. Also Markdown (zip).
  • Flashcards linked to pages by a stable page ID: a cards button with badge at the top right of every page (⇧⌘K), a side panel, a Flashcards section on subject pages and "Flashcards in This Folder".
  • Rich-text flashcards with auto-growing fields and a live preview; long card faces scroll and scale gently when studying.
  • Editor: a floating formatting menu, a fuller fixed toolbar, fonts, alignment, superscript and subscript, block handles with drag and a block menu, a grouped "/" menu with recents, columns, table of contents, dates, images with size, caption and alignment, code blocks with a language picker and copy button, maths editing with live preview, callouts with emoji and colour.
  • Planner: semester setup (with Macquarie's 2026 dates), week numbers, class timetable with .ics import, tasks with natural-language quick add and recurrence, assessment milestones and behind-schedule warnings, exam details, Plan My Week, I'm Behind, exam revision planning, Day/Week/Month/Semester/Agenda views, workload and clash warnings, weekly summary and review, Today on Home, class/task/milestone/study notifications with snooze and quiet hours, two-way Calendar sync, Reminders sync, PDF and .ics export.
  • What's New screen.

Changed

  • Search starts at the top of the window, groups results by subject, shows where each result lives, works from the keyboard, and opens pages at the match. All screens now start at the top.
  • The command palette moved from ⌘K to ⇧⌘P (⌘K is now Link). Back and Forward moved to ⌃⌘← and ⌃⌘→ (⌘[ and ⌘] now outdent and indent).

Fixed

  • Long sources are no longer cut off ("only the first part was used").
  • Results of AI jobs are no longer lost if you move to another page while they run.
